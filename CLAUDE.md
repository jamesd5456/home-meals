# Home Meals site

Standing rule for `data/shopping.json`: a shopping list holds only the ingredients the recipes in `data/recipes.json` use, in the exact amounts they need. No assumed staples, snacks, buffers or spare quantities. Add up the recipe ingredient lines for the meals scheduled in the list's window, and note the recipe beside each item. Stock is always preferred over water: never write "stock or water" in a recipe, use no-salt-added stock and put it on the list. In recipe cards, keep ingredient lines clean (no "diced", "chopped" etc.) and put each prep job (cutting, dicing, grating, draining and rinsing, thawing, toasting) into the step where the ingredient is first used. Skip optional items, and where a pack can't be bought in the exact amount write "buy the smallest pack". If a week's recipes don't exist yet, leave its list empty.

Keep personal details (names, dates of birth, roster, health history) out of this public repo. Run `npm test` before pushing.

Shopping list shape: `data/shopping.json` holds one list (no weekly lists). New weeks' items are added to its flat `items` array of `{ id, text, section }`, and ids should be unique and stable (ticks and clears are saved against them). An item carried over from an older list keeps `list` set to that list's id so its saved tick still applies. Shopping is on the Sunday before each Mon to Sun cooking week. Put every ingredient for the week on the list; items likely at home go in the `home-check` section with the amount the recipe needs. `section` is a key from `data/store-layout.json`, which holds the sections in store-walk order (separate butcher and grocer stops first, then Woolworths Woolooware Bay aisles). All meat and seafood goes in the `meat` section (the Woolworths butcher) by default; James decides case by case what comes from the separate butcher, and only then is an item given the `butcher` section. The app builds the groups from that file, so reordering the file reorders every list. Don't hand-group items in `shopping.json`. When the layout is confirmed against the real store, set `"verified": true` and add `aisle` numbers.
